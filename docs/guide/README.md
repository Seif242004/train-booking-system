# Train Booking System: code guide

A guide to read the whole project top to bottom. It is written for a computer engineering student who knows Java and JavaScript but is new to
Spring Boot, the Express Gateway, Keycloak, Stripe and the patterns used here. Each chapter says what a part does, why it is built that way and
which files to open. Paths are in code font so you can open them.
